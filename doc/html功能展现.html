## 核心观点

为什么不是自动补全

斜杠菜单只在你明确敲出 / 时出现，不会在正常输入里打断你。斜杠前必须是行首、空白或中文标点，所以路径 a/b 和网址不会误触发。

中英文都能搜

输入 标题 或 h2 都能筛到同一条；每条命令右侧直接显示将要插入的语法。
