# MarkWright v0.4.8

> 专业 Markdown 编辑器 · 完全本地 · 零联网 · 零云同步

本次更新是一次**完整的代码审查与性能改造**版本。我们在保持功能稳定的前提下，修复了资源泄漏与高频写入问题，重做了首屏加载与长文档渲染路径，并收紧了本地加密的密码处理方式。

---

## ✨ 本版亮点

### 更快的启动与更轻的首屏

重做了构建分包策略：首屏只保留必需的基础模块，其余重型能力（图表、公式、流程图、文档导出）全部改为**按需加载**——文档里没有用到，就完全不会加载。

- 入口脚本体积显著下降，重型依赖拆分为独立分块
- 流程图与图表**进入视口才渲染**，长文档首屏不再卡顿
- 同一张流程图重复出现时复用渲染结果，不重复计算

### 更顺滑的编辑与预览

- 预览渲染改为**输入合并**：连续输入时合并为一次渲染，光标移动不再触发重渲染
- 切换标签页时立即渲染，不再有延迟
- 重渲染前统一释放上一轮的图表实例与看板组件，杜绝内存增长
- 每个标签页独立保留**滚动位置、光标选区与撤销历史**

### 更省资源的后台行为

- 字数统计由「每次击键写入一次」改为**合并写入**，写入频次大幅下降；切换标签或退出时强制落库，数据不丢
- 修复环境音「森林」模式下定时器与音频节点**永不释放**的泄漏
- 修复看板组件在预览刷新时重复挂载导致的实例泄漏
- 会话、大纲等定时器与监听均随作用域销毁释放

### 更安全的主密码处理

- 主密码**不再写入浏览器本地存储**。改为仅保存一份「用该密码加密后的校验串」，且存放于原生层
- 密码使用后立即从组件状态清除，不打印日志、不落任何可读存储
- 加密算法为 **AES-256-GCM**，每次加密使用独立随机数，加密文件带专属标识头，非本程序生成的文件会被直接拒绝

### 知识网络与工作区

- 工作区扫描改为**并发读取**，大幅缩短大型工作区的扫描等待
- 反向链接现在会带上**出现的行号与上下文原文**，不再只是一个文件名列表
- 仅扫描 Markdown 文件，跳过二进制文件与超大文件；隐藏目录与常见构建产物目录自动忽略

### 大纲与统计

- 大纲面板在标题数量很多时启用**虚拟滚动**，滚动依旧顺滑
- 写作统计新增**近 90 天热力图**与**近 30 天趋势**，数据全部存储在本机

### 界面与交互

- 侧边栏宽度支持拖拽调整并自动记忆，双击恢复默认
- 关闭标签页后激活**相邻标签**，不再跳回第一个
- 通知改为统一的浮层提示，覆盖保存、打开、加密等全部操作结果
- 新增若干处键盘可达性改进

## ⚠️ 已知限制

以下为当前版本的**明确限制**，请在升级前知悉：

- **备份需要手动触发**。保存文件时不会自动生成备份副本；请在加密面板中手动执行备份操作。
- **工作区加密为部分实现**。设置主密码后会建立密码校验，但保存文件时的自动加密尚未实现；当前加密仅针对当前文档手动执行。
- **启动时不恢复上次打开的标签页**。这是有意设计：避免与「双击 Markdown 文件直接打开」相互抢占，确保你双击的文件一定出现在最前面。工作区与界面布局仍会恢复。
- **命令面板中的「备份当前文件」与 F10 番茄钟切换暂未接通**。请分别从加密面板与专注模式界面中使用对应功能。
- **仅提供桌面端**。移动端形态暂未实现。

## 🔧 技术概要

| 项 | 说明 |
|----|------|
| 运行形态 | 桌面原生应用，界面基于 Web 技术构建 |
| 编辑器内核 | 与专业代码编辑器同源，支持多光标、折叠、括号匹配、历史 |
| 本地存储 | 内嵌轻量数据库，用于写作统计与配置；正文为纯文本文件 |
| 加密 | AES-256-GCM，密钥由主密码派生 |
| 离线能力 | 全部核心功能离线可用；不产生任何遥测或数据上报 |
| 文件格式 | 内容始终为标准 Markdown，图片为普通图片文件，无格式锁定 |

## 🙏 说明

本版本聚焦于「让长期使用更可靠」：更少的资源泄漏、更低的写入频次、更克制的加载策略，以及更严谨的密码处理。

如果你的使用场景涉及上述「已知限制」中的功能，请先阅读对应说明；我们会在后续版本中逐步完善。
